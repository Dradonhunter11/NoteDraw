# NoteDraw — Agent Memory (`MEMORY.md`)

Persistent architectural notes, decisions, and platform constraints for future agents working on **NoteDraw**.

## Project & User Decisions
- **Single Design File**: Only keep one `DESIGN.md` at the repository root (`c:\Users\alexa\Documents\Github\NoteDraw\DESIGN.md`). Do not create a duplicate `Design/Design.md`.
- **Core UX Approach**: Approach A — Obsidian-style local folder Vault containing `.md` notes (Markdown + LaTeX + embedded ```` ```drawing ```` blocks) and standalone `.ndraw` vector drawing files.
- **Closable Views & `View` Toolbar Tab**: Every panel (`Vault Explorer`, `Outline & Tags`, `Formatting Sub-Toolbar`, `Editor Pane`, `Live LaTeX Code Preview`, `Document Preview Pane`, `Status Bar`) must be independently closable via a header `×` button and restorable from the **`View`** tab in the top toolbar (plus a `Reset All Views` action).
- **Live LaTeX Preview While Typing**: While typing inside Obsidian-style ```` ```latex ````, ```` ```math ````, `$$...$$`, or `$...$` blocks, the live preview must render the formula immediately without waiting for manual refresh or breaking on half-typed expressions.

## Tech Stack & Dependency Notes
- **Runtime & UI**: `.NET 10.0` (`net10.0`), `Avalonia 12.0.4`, `Avalonia.Desktop 12.0.4`, `Avalonia.Themes.Fluent 12.0.4`, `Avalonia.Fonts.Inter 12.0.4`.
- **Avalonia 12 API Notes**:
  - `TextBox` uses `PlaceholderText` (not obsolete `Watermark`).
  - `IClipboard.SetTextAsync` is an extension method in `Avalonia.Input.Platform` (`ClipboardExtensions`).
  - `ForegroundProperty` on `Button` resolves via `Button.ForegroundProperty` (`TemplatedControl.ForegroundProperty`).
- **Approved Extra Library (Rule 2)**: `Markdig` (`1.6.0`) for Markdown + Math + Pipe Tables + Task Lists AST parsing.
- **SkiaSharp Compatibility Warning**: `Avalonia.Skia 12.0.4` pulls in `SkiaSharp 3.119.4`. Do **NOT** install `CSharpMath.SkiaSharp` (compiled against SkiaSharp 2.80, throws `MissingMethodException` for `SKPaint.TextSize` on SkiaSharp 3.x). LaTeX rendering is implemented natively on Avalonia `DrawingContext` in `Rendering/Latex/`.
- **Avalonia 12 Compiled Bindings**: `NoteDraw.csproj` sets `<AvaloniaUseCompiledBindingsByDefault>true</AvaloniaUseCompiledBindingsByDefault>`. Prefer strongly-typed C# UI construction or explicit `x:DataType` bindings to avoid XAML compiled binding issues.

## Key Implementation Invariants
- **Inline Drawing Sync & Immediate Close Refresh Guard**: When `MarkdownPreviewControl.InlineDrawingUpdated` updates the Markdown source in `MainWindow`, `_suppressPreviewRebuild = true` prevents destroying the open `DrawingWorkspaceControl` mid-stroke, while `RenderInlineDrawingCard` / `RenderEmbeddedNdrawCard` immediately update `_markdown` and `_embeddedDrawingCache` on `DocumentChanged` and flush on `"✓ Done Editing Image"` so the collapsed preview reflects new strokes instantaneously.
- **Vault Explorer Multi-Select, File Clipboard, Slim Scrollbars & Single-Vault Isolation**:
  - `VaultService` supports `CreateFolder(...)`, `VaultEntryKind.ImageFile`, `RegisterExternalFolder(displayName, fullPath)`, `ClearExternalFolders()`, starter `Notes/Quick Reference.md` subfolder creation, folder-preserving filtered `GetEntries(...)`, and fault-tolerant directory/file reads; `MainWindow` provides collapsible (`▼`/`▶`) folder rows (`_collapsedVaultFolders`) and `OpenDocumentTab.IsImage` preview handling (including `.svg` info cards).
  - `MainWindow` tracks multi-file/folder selection (`_selectedVaultPaths` with `Ctrl+Click` toggle, `Shift+Click` visible range via `_visibleVaultEntryOrder`, `Ctrl+A` file select-all, and in-place `UpdateVaultSelectionVisuals()` highlighting without tearing down right-clicked rows before `ContextMenu.Opening` runs), dynamic row & root `ContextMenu` (`Cut`, `Copy`, `Paste`, `Select All Files`, `Delete`), and Vault Explorer shortcuts (`Ctrl+X`, `Ctrl+C`, `Ctrl+V`, `Del`, `Ctrl+A` in `OnWindowTunnelKeyDown`) strictly gated on `_isVaultExplorerFocused && FocusManager.GetFocusedElement() is not TextBox && !hasModalOpen`.
  - `VaultService.PasteEntries(...)` handles recursive file/folder copy (`Name - Copy.ext` collisions) and move (updating open tab paths via `RemapOpenTabsAfterMove`), plus `OpenVault` clearing `_externalFolders` and `EnsureVaultInitialized(bool seedSampleIfEmpty = true)` so only the default `SampleVault` receives starter files or registers external `<exe>/canvas` and `<exe>/image` roots. `OpenVaultAtPath` clears `_openTabs`, `_selectedVaultPaths`, `_clipboardVaultPaths`, `_collapsedVaultFolders`, and `_markdownPreview` inline drawing histories before opening a vault, and `_isOpeningVaultPicker` guards `OpenVaultFolderAsync`.
  - `App.axaml` defines `<x:Double x:Key="ScrollBarSize">6</x:Double>` and `AllowAutoHide="False"` non-overlay styles hiding `PART_LineUpButton` / `PART_LineDownButton`, paired with dedicated bottom/right `Margin` gutters on `_tabsStrip` and `_vaultListStack`.
- **Obsidian Vault Images, Last Vault Persistence & Git Integration**: `DocumentAssetService.CleanObsidianImageTarget` / `ResolveImagePath` strip Obsidian `|width`, `#section`, `<...>`, and `%20` wrappers and search active directory + vault subfolders for shortest-path images without ever auto-creating `.ndraw` canvases (`TryLoadExistingCanvas`). `MarkdownPreviewControl.BuildEditorSegments` checks `IsImageExtension(cleanTarget)` before `.ndraw` embeds and guards segment rendering against malformed inputs. `ThemeConfigService.GetSavedLastVaultPath()` persists `LastVaultPath` in `<exe>/canvas/app_options.json` so `MainWindow` reopens the last opened vault at startup. `GitService` (`Services/GitService.cs`) integrates `git` CLI (`InitRepository`, `GetStatus`, `StageAndCommitAll`, `CommitAndPush`, `Pull`, `Push`, `SwitchOrCreateBranch`, `SetRemoteOrigin`, `GetDiff`) via `MainWindow`'s `Git` menu, `🔀 Git` ribbon tab, status badge, and `Ctrl+Shift+G` panel.
- **Executable-Relative Assets (`<exe>/image` & `<exe>/canvas`) & Tight Image/Canvas Bounds**: `DocumentAssetService` saves copied/pasted/imported images into `<exe>/image` (reusing existing `<exe>/image` files without duplicating on drag/import), saves document drawing canvases into `<exe>/canvas`, and persists remembered quick-select colors in `<exe>/canvas/remembered_colors.json`. `DrawingDocument.GetUsedBounds(...)` frames collapsed inline/embedded drawing previews (`BuildInteractiveDrawingImageBlock`) and `MarkdownPreviewControl.RenderCanvasToBitmap(doc)` tightly around used stroke content, while `RenderMarkdownImageCard` uses left-aligned natural/clamped dimensions with `Background = Brushes.Transparent` (no full-page whitespace).
- **Auto-Save Option, Image Drag-Drop & Exit Prompt**: `ThemeConfigService` persists `Config.AutoSave` in `<exe>/canvas/app_options.json`, toggled via `Options -> Auto-Save Documents While Editing` in `MainWindow`'s top menu. When Auto-Save is enabled, text and canvas edits save immediately to disk; when disabled with dirty tabs on exit (`OnMainWindowClosing`), `MainWindow` cancels close and displays the modal MessageBox overlay (`ShowUnsavedExitMessageBox` / `ApplyUnsavedExitDecision`) to Save, Discard, or Cancel exiting. Dragging images from Vault Explorer's `image` folder or via OS `DragDrop` resolves the target line at mouse release (`GetDocumentLineAtPoint`) and inserts at that line via `InsertImageMarkdownAtLine`.
- **Canvas Resize Controls**: `DrawingCanvasControl.ResizeCanvas(w, h)` and `FitCanvasToUsedBounds()` push undo snapshots so dimensions undo/redo cleanly alongside strokes; `DrawingWorkspaceControl` exposes `W × H` inputs, `Resize`, `Fit Bounds`, and a bottom drag-to-resize bar inside a scrollable container.
- **Unified Undo/Redo Architecture**: `TextBox.IsUndoEnabled = false` on the Markdown editor; `TextUndoManager` coalesces consecutive character insertions/deletions into multi-character bursts, while `DrawingCanvasControl` maintains full `DrawingDocument` undo/redo stacks (preserved across inline preview re-renders by `MarkdownPreviewControl._inlineDrawingHistories`).
- **Checklist & Math Rendering**: `MarkdownPreviewControl` inherits `Border` (not `UserControl`), uses `NormalizeMathBlocks(...)` / `NormalizeMathBlocksWithMap(...)` before Markdig parsing, avoids fixed `LineHeight` on `SelectableTextBlock`, and renders `CodeInline` as a native `Run` to prevent bottom-half line clipping.
- **Separate Theme Files (`dark.json` & `light.json`)**: `ThemeConfigService` loads/saves separate `dark.json` and `light.json` files (in the active Vault or repo root) and custom `.json` palettes (`LoadPaletteFromFile`, `SavePaletteToFile`) with safe hex fallback (`ThemeConfigService.ParseColor(...)`) and `#FFFFFF` white drawing canvas defaults.
- **White Canvas, Brush Eraser & Right-Click Color Selector**: `DrawingCanvasControl` renders on a crisp `#FFFFFF` surface with a live tool/coordinate mouse preview (`DrawMousePreview`) and freehand brush `DrawingToolKind.Eraser` (`#FFFFFF` strokes preserving partial lines and undo/redo). `DrawingWorkspaceControl` replaces fixed toolbar swatches with a compact color selector button and a right-click floating sub-menu (`ColorSpectrumPickerControl` + Hue/RGB/Hex/Quick Tools).
- **H1–H5 Editor Section Folding**: `FoldableEditorControl` and `EditorFoldManager` fold `H1`–`H5` heading sections in the visible editor while reconstructing the complete Markdown source via `EditorFoldManager.GetFullUnfoldedText(...)` before saving, previewing, or applying toolbar formatting edits.
- **Unified 1-Window Live-Cursor Editor, Image Context Menu, Keyboard Deletion & Toolbar Menu**: `MainWindow` merges Markdown editing and preview into a single unified window toggling between `_markdownPreview` (`Unified Live View`) and `_foldableEditor` (`Raw Source Mode`), with a responsive top toolbar (`Menu` with `File`, `Edit & Insert`, `View & Mode`, `Theme` plus wrapping quick-action buttons in a `WrapPanel` so narrow windows never overlap). In `MarkdownPreviewControl`, single-clicking any block or navigating with arrow keys (`Up`/`Down`/`Left`/`Right`, `Enter`, `Backspace`) activates that line directly as raw Markdown (`# {text here}` on headings) with inline live LaTeX preview while keeping non-cursor lines rendered. Clicking an ```` ```drawing ````, `![[*.ndraw]]`, or Markdown image card opens its editor in place; right-clicking opens a `ContextMenu` (`✎ Edit Image`, `📋 Copy Image`, `🗑 Delete Image`); and pressing `Backspace` immediately after a picture or `Delete` immediately before a picture (or `Delete`/`Backspace` on a focused image frame) removes the image block purely via keyboard (`RemoveLineRange`, `DeleteImageBlockAtLineRange`). Top Markdown/LaTeX insertion toolbars are removed in favor of the main toolbar **`?`** help button (and `F1`) opening `SyntaxGuideSubMenuControl`.
- **Headless Self-Tests (`TEST.md`)**: `dotnet run --project NoteDraw.csproj -- --self-test` initializes Avalonia platform services via `BuildAvaloniaApp().SetupWithoutStarting()` and runs `SelfTestRunner.RunAll()`, following the mandatory **One Test Per Feature (Never One Test Per Branch)** guideline documented in `TEST.md` (isolated per-feature tests with `WithTempVault` and `SaveAndRestoreFile` cleanup).
