# NoteDraw Architecture Overview

> Generated maintenance documentation per `AGENT.md` Rule 5.

## High-Level Design
NoteDraw is a local-first C# / Avalonia UI (`net10.0`, `Avalonia 12.0.4`) note-taking application organized around three core subsystems:

1. **Vault, Assets & State Management (`Services/`)**:
   - `VaultService`: Reads/writes `.md` notes, `.ndraw` drawings, folders (`CreateFolder`, starter `Notes/` subfolder), and `VaultEntryKind.ImageFile` entries inside the active Vault and default-vault external asset folders (`RegisterExternalFolder`, `ClearExternalFolders`) using fault-tolerant enumeration and `FileShare.ReadWrite` reads, preserves folders during filtered queries (`GetEntries`), copies/moves batched files and folders (`PasteEntries` with unique ` - Copy` naming and ancestor/descendant safety guards), enforces opt-in starter seeding (`EnsureVaultInitialized(bool seedSampleIfEmpty = true)`), extracts headings/tags/wiki-links, and resolves `[[WikiLink]]` targets.
   - `DocumentAssetService`: Scopes pasted/imported images (`<vault>/image`: `SavePastedBitmap`, `ImportImageFile` without duplicating files already in `ImageFolderPath`, `CleanObsidianImageTarget`, recursive vault `ResolveImagePath`) and document drawing canvases (`<vault>/canvas`: `CreateSavedCanvas`, `SaveInlineCanvasToCanvasFolder`, `TryLoadExistingCanvas`, `LoadOrCreateCanvas`, `SaveCanvas` with filename sanitization) to the active vault via `SetActiveVaultPath(vaultPath)` (creating asset folders lazily on write, with `<exe>/image` and `<exe>/canvas` as parameterless/legacy fallbacks).
   - `ThemeConfigService`: Loads and saves separate `dark.json` and `light.json` palette/typography files (`ThemePalette.CreateClassicDark()`, `ThemePalette.CreateClassicLight()`, `LoadPaletteFromFile`, `SavePaletteToFile`) with safe hex parsing (`ParseColor` / `ParseBrush`) and `#FFFFFF` white drawing canvas defaults, plus `app_options.json` (`Config.AutoSave`, `Config.LastVaultPath`, `GetSavedLastVaultPath`, `LoadOptions`, `SaveOptions`).
   - `GitService`: Wraps the system `git` CLI (`GetStatus`, `InitRepository`, `StageAndCommitAll`, `Pull`, `Push`, `CommitAndPush`, `SetRemoteOrigin`, `SwitchOrCreateBranch`, `GetDiff`) for vault version control.
   - `CrashLoggerService`: Configures `log4net` (`RollingFileAppender`) outputting daily crash and unhandled-exception logs (`notedraw-yyyy-MM-dd.log`) into `<exe>/Logs/`, wired to `Program.Main`, `App.OnFrameworkInitializationCompleted`, `AppDomain.CurrentDomain.UnhandledException`, `TaskScheduler.UnobservedTaskException`, and `Dispatcher.UIThread.UnhandledException`.
   - `PlatformShortcuts`: Centralizes OS-aware command modifiers (`KeyModifiers.Meta` / `Cmd` exclusively on macOS; `KeyModifiers.Control` / `Ctrl` exclusively on Windows/Linux) across global shortcuts, canvas/editor handlers, multi-select clicks, menu labels, and tooltips.
   - `EditorFoldManager`: Detects `H1`–`H5` Markdown sections (`DetectSections`), manages per-heading fold/unfold state (`ToggleFoldAtLine`, `FoldSectionAtLine`, `UnfoldSectionAtLine`, `UnfoldAll`), computes gutter metadata (`GetGutterLines`), and reconstructs hidden content (`GetFullUnfoldedText`).
   - `ViewLayoutState`: Centralizes open/closed state for every workspace view (`VaultExplorer`, `OutlineTags`, `FormattingToolbar`, `EditorPane`, `LiveLatexPreview`, `PreviewPane`, `StatusBar`) and coordinates view visibility toggles inside the top toolbar **`View & Mode` → `View`** submenu.
   - `SelfTestRunner`: Headless-capable verification suite of atomic single-feature tests authored per `TEST.md` and executed via `dotnet run -- --self-test`.

2. **Native Vector LaTeX Engine (`Rendering/Latex/`)**:
   - `LatexSymbolTable`: Static lookup tables for symbols, big operators, named functions, blackboard bold characters, accents, and spacing.
   - `LatexAst` & `LatexParser`: Fault-tolerant recursive-descent parser returning `LatexParseResult` (AST + non-blocking diagnostics while typing).
   - `LatexMathRenderer` & `LatexMathControl`: Recursive `MathBox` box-layout engine drawing fractions, roots, matrices, scripts, accents, and scalable delimiters directly onto Avalonia `DrawingContext`.
   - `LatexLiveDetector`: Caret-aware scanner detecting ```` ```latex ````, ```` ```math ````, `$$...$$`, and `$...$` contexts as the user types.

3. **Markdown, Live Cursor Editor, Syntax Guide & Vector Hand Drawing (`Rendering/` & `Drawing/`)**:
   - `FoldableEditorControl`: Pairs the Markdown `TextBox` (`InnerTextBox`) with `HeadingFoldGutterControl` and a folded-sections banner for `H1`–`H5` gutter fold toggles (`▼` / `▶`) while keeping full unfolded source synchronized via `FullText`.
   - `MarkdownPreviewControl` & `CodeSyntaxHighlighter`: Obsidian-style segment-based live-preview text editor (`BuildEditorSegments`, `ActivateSegmentAtLine`, `MoveCursorToAdjacentSegment`). Single-clicking or moving the keyboard cursor onto any line preserves `_scrollViewer.Offset` (`BringIntoViewOnFocusChange = false`, `RequestBringIntoViewEvent` handled unconditionally, and `_pendingScrollOffsetRestore` stabilized through `DispatcherPriority.ContextIdle`) and reveals raw Markdown (`# {text here}`, `- [ ]`, `$$...$$`, ```` ```lang ```` / `~~~lang` with `Tab` indentation, etc.) with inline live LaTeX preview while non-cursor lines remain rendered via `Markdig` (`1.6.0`). Fenced code blocks (`RenderCodeCard`) tokenize and render syntax-highlighted `Run` spans via `CodeSyntaxHighlighter` (`C#`, `Python`, `JS/TS`, `C/C++`, `Java`, `Kotlin`, `Rust`, `Go`, `JSON`, `HTML/XML/AXAML`, `CSS`, `SQL`, `Bash/PowerShell`, `YAML/TOML`) with theme-aware Dark+/Light+ palettes, language badge, line-number gutter, and copy action. Regular Markdown/pasted images (`RenderMarkdownImageCard`) render cleanly like Word/Obsidian without edit chrome (`ContextMenu`: `Copy Image`, `Delete Image`), and all picture cards are wrapped by `WrapPictureCardWithAdjacentCursor` / `CreatePictureAdjacentCursorTextBox` (`ActivatePictureAdjacentCursor`) so clicking before/after or on the left/right half of a picture places a classic cursor right next to it (preserving focus across `PointerReleased`) for typing, `Enter`, arrow navigation, or `Backspace`/`Delete`. Vector ```` ```drawing ```` and `![[*.ndraw]]` cards support click-to-edit (`OpenInlineImageEditor`, `PrepareEmbeddedCanvasForOpen` to reset active cursor segments when inserting `+ Canvas in Doc`, tight `RenderCanvasToBitmap`, `BuildImageContextMenu` with `Edit Image`, `Open in a seperate tab`, `Copy Image`, `Delete Image`, plus `OpenCanvasInSeparateTabRequested` -> `MainWindow.OpenCanvasInSeparateTab`). Also supports `H1`–`H5` folding (`TogglePreviewHeadingFold`), clickable `[[WikiLinks]]` / `#tags`, pure keyboard adjacent-image deletion (`DeleteImageBlockAtLineRange`, `RemoveLineRange`), and line-accurate drag-and-drop image insertion (`GetDocumentLineAtPoint`, `InsertImageMarkdownAtLine`, `ImageFileDroppedAtLine`).
   - `SyntaxGuideSubMenuControl`: Searchable, categorized read-only reference sub-menu (`AllEntries`) explaining Markdown, LaTeX Math (with live `LatexMathControl` previews), and Drawing/Image syntax.
   - `DrawingModels`, `DrawingCanvasControl`, & `DrawingWorkspaceControl`: White `#FFFFFF` vector drawing engine with `GetUsedBounds(...)`, live mouse cursor preview (`DrawMousePreview`), smooth quadratic-Bezier pen, highlighter, freehand brush `Eraser`, `Pipette` color sampler (`SampleColorHexAtCanvasPoint`, `PickColorAtCanvasPoint`, `ColorPickedByPipette`), pasted canvas images (`DrawingToolKind.Image` with `ImageBase64`, `PasteBitmap` / `PasteImageFile` / `PasteImageBase64`, SVG `<image>` export, `RenderToBitmap`, `CopyCanvasToClipboardAsync`, `PasteImageFromClipboardAsync`, `SharedInAppClipboardBitmap`), geometric shapes (`Line`, `Arrow`, `Rectangle`, `Ellipse`), text/LaTeX labels (`TextLabel`), pan/move/selection tools (`SelectPan`, `MovePosition`, `SelectArea` with `DrawingRect`/`ClipRect` masking and `< 5×5`/double-click/`Escape` cancellation, `MoveSelection`, `ResizeSelection` with 8 corner/edge handles), single-key tool shortcuts (`TryMapKeyToTool` / `TryHandleToolShortcut`: `P`/`1`, `H`/`2`, `E`/`3`, `I`/`K`/`4`, `L`/`5`, `A`/`6`, `R`/`7`, `O`/`C`/`8`, `T`/`9`, `V`/`M`, `G`, `S`, `W`, `Q`), tablet stylus (`PointerType.Pen` / `IsEraser`) capture-safe stroke commit (`CommitActiveStroke` on `OnPointerReleased` & `OnPointerCaptureLost`) with canvas-originating scroll-gesture isolation (`IsPointerPressedOnCanvas` / `IsPointerPressedInCanvas`), anchored mid-stroke zoom (`SetZoomAroundPoint`, wheel, pinch, `+`/`-`/`Ctrl+0`, toolbar & sub-menu 25%–400% sliders), undoable canvas resize (`ResizeCanvas`, `FitCanvasToUsedBounds`, `W × H` toolbar inputs, and bottom drag handle), right-click floating sub-menu (`ColorSpectrumPickerControl` 2D HSV + RGB/Hex selector + `🧪 Pipette` + quick tools + `📋 Paste Image` / `📋 Copy Canvas`), Undo/Redo, PNG export (`RenderTargetBitmap`), SVG export, and per-tool documentation in `docs/canvas/`.

4. **Workspace Shell (`MainWindow.axaml`, `MainWindow.axaml.cs`, `App.axaml`)**:
   - `App.axaml` configures slim `6px` non-overlay scrollbars (`ScrollBarSize = 6`, `AllowAutoHide = False`, hidden `PART_LineUpButton` / `PART_LineDownButton`) alongside reserved gutter margins on `_tabsStrip` and `_vaultListStack`.
   - `MainWindow` enforces single-vault activation across startup (`ThemeConfigService.GetSavedLastVaultPath()`) and switching (`OpenVaultAtPath` unloads open tabs, selection, clipboard, and inline histories first and guards `OpenVaultFolderAsync` re-entrancy via `_isOpeningVaultPicker`), hosts the non-overlapping wrapping top toolbar (`Menu` with `File`, `Edit & Insert`, `View & Mode` [including the **`View`** submenu for Workspace View toggles and `Reset All Views`], `Options` [`Auto-Save` toggle], `Git`, and `Theme`, plus wrapping quick-action controls and the `?` Syntax Guide button inside a `WrapPanel`), 2-tab ribbon (`Drawing Tools`, `🔀 Git`), left sidebar (collapsible `Vault Explorer` with multi-file `Ctrl+Click` / `Shift+Click` / `Ctrl+A` selection, dynamic right-click `ContextMenu` and keyboard `Ctrl+X`/`Ctrl+C`/`Ctrl+V`/`Del` file operations gated on Vault Explorer focus, `+ Note`, `+ Folder`, `Notes`, `Outline & Tags`), single unified 1-window Editor & Preview (`_previewContentHost`) switching cleanly between live cursor Markdown/Image editor (`_markdownPreview`), raw foldable source (`_foldableEditor`), standalone drawing canvas (`_standaloneDrawing`), and image/SVG preview tabs, unsaved-work exit confirmation MessageBox (`OnMainWindowClosing` / `ShowUnsavedExitMessageBox` / `ApplyUnsavedExitDecision`) when Auto-Save is off, Git Source Control modal (`_gitOverlay`, `Ctrl+Shift+G`), Live LaTeX preview docked below, status bar with clickable Git branch badge, Quick Switcher (`Ctrl+P`), and separate `dark.json`/`light.json` theme hot-reload.

## Maintainer Extension Index (Where to Add Things in the Future)

| What You Want to Add | File to Edit | Symbol / Section to Update |
| --- | --- | --- |
| New LaTeX symbol or function | `Rendering/Latex/LatexSymbolTable.cs` | `Symbols`, `BigOperators`, `NamedFunctions`, `BlackboardBold` |
| New LaTeX AST construct / command | `Rendering/Latex/LatexAst.cs`, `LatexParser.cs`, `LatexMathRenderer.cs` | `LatexNode`, `ParseCommand()`, `MeasureNode()` |
| New Syntax Guide how-to entry | `Rendering/SyntaxGuideSubMenuControl.cs` | `AllEntries` |
| New Markdown segment, block, or image renderer | `Rendering/Markdown/MarkdownPreviewControl.cs` | `BuildEditorSegments()`, `RenderParsedBlock()`, `AppendInline()`, `RenderMarkdownImageCard()` |
| Editor `H1`–`H5` section folding / gutter rendering | `Services/EditorFoldManager.cs`, `Rendering/FoldableEditorControl.cs` | `DetectSections()`, `GetGutterLines()`, `HeadingFoldGutterControl.Render()` |
| Theme palette fields or `dark.json`/`light.json` options | `Services/ThemeConfigService.cs`, `dark.json`, `light.json` | `ThemePalette`, `ThemeConfigService.Load()`, `LoadPaletteFromFile()` |
| New Drawing tool, cursor preview, or right-click sub-menu option | `Drawing/DrawingModels.cs`, `DrawingCanvasControl.cs`, `DrawingWorkspaceControl.cs` | `DrawingToolKind`, `OnPointerPressed()`, `DrawMousePreview()`, `BuildContextSubMenuPopup()` |
| New Canvas background pattern | `Drawing/DrawingModels.cs`, `DrawingCanvasControl.cs`, `DrawingWorkspaceControl.cs` | `CanvasBackgroundKind`, `DrawBackgroundPattern()` |
| New closable Workspace View or unified mode | `Services/ViewLayoutState.cs`, `MainWindow.axaml.cs` | `WorkspaceViewKind`, `SetUnifiedWindowMode()`, `RefreshViewLayout()`, `UpdateViewToggleLabels()` |
| Automated per-feature self tests | `Services/SelfTestRunner.cs`, `TEST.md` | `RunAll()` (follow 1-feature-per-test rule) |
| Pasted image & canvas folder resolution | `Services/DocumentAssetService.cs` | `SetActiveVaultPath()`, `SavePastedBitmap()`, `CreateSavedCanvas()`, `ResolveImagePath()`, `ResolveCanvasPath()` |
